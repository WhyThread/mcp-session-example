# Triage one supplied session

Start the local server from the repository root, then open `/worksheet/`. The invented six-call sample loads automatically. Use **Paste JSONL** or **Open a file** for a compatible file you have permission to review.

Most exported logs need manual conversion first. Raw MCP JSON-RPC messages are not imported directly. The page handles the documented [narrow format](../docs/format.md), keeps missing status unknown and leaves relevance judgments to you. It does not establish task completion.

Read the [browser guide](session-triage-guide.html) or [Markdown guide](session-triage-guide.md). Remove secrets and personal data before loading a file. The worksheet does not upload your log or save it in browser storage; your browser may restore form text.
