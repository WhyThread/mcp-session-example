      How to read the flags

      Retries need a valid retry_of line reference to an earlier error from the same tool. Repeated tool names alone aren't enough.

      “Value reappears” means an exact string from a recorded return appears in later arguments. It doesn't prove causation or that the agent used the result correctly.

      Your triage note

      Accepted format, limits and source

      This is a small JSONL reader, not a universal log importer. Each object needs a nonempty tool, tool_name or name. Optional argument objects: args, arguments, params or input. Optional return fields: returned_ids, result or output.

      An explicit ok boolean or isError boolean provides a status. A nonempty error also flags an error. A result alone doesn't establish success. Missing status stays unknown; conflicting status fields are flagged.

      retry_of is an optional 1-based physical JSONL line number. Links across different explicit session IDs are rejected. Exact matches cover strings of 4–200 characters in return fields, including common words. Numbers aren't compared. Matching inspects at most six nested levels and 250 strings per field, and shows at most 24 matches per record; it is not exhaustive. A missing session ID means source identity is unverified.

      Limit: 2 MiB and 2,000 lines. Unreadable lines are shown as skipped with their line numbers. Counts describe only accepted records, never complete capture. This worksheet makes no model calls and uses no cookies or browser storage. It does not upload your log.
